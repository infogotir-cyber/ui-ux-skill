Introduce tus credenciales de API

Settings → Integrations → API Key en GHL

Settings → Business Info → Location ID

Dónde encontrar el token en GHL:
  1. Settings → Integraciones Privado
  2. Clic en "panel de control"
  3. Copia el campo API Key / Access Token
  4. Verifica que tenga los scopes: contacts.readonly, opportunities.readonly
Solución al error de red (CORS):
El navegador bloquea llamadas a APIs externas cuando el archivo se abre localmente. Soluciones:
Opción 1 — GitHub Pages (gratis): Sube el archivo a tu repo → Settings → Pages → activar
Opción 2 — VS Code: Instala extensión "Live Server" → clic derecho en el archivo → "Open with Live Server"
Opción 3 — Netlify Drop: Arrastra el archivo a netlify.com/drop

Nota: Las credenciales se guardan solo en tu navegador (localStorage). Nunca se envían a ningún servidor externo.
